# PlayVault

Веб-приложение для ведения личной коллекции видеоигр на PHP и PostgreSQL.

Пользователь может сохранять игры с разных платформ в одном списке, отмечать статус прохождения, выставлять оценку, учитывать часы, добавлять заметки и избранное. Данные вводятся вручную. У каждого аккаунта собственная коллекция.

## Возможности

- Регистрация, авторизация и выход из аккаунта.
- Добавление, просмотр, редактирование и удаление записей.
- Поиск, сортировка и фильтрация по статусу, жанру и избранному.
- Статистика по личной коллекции и прогрессу прохождения.
- Адаптивный интерфейс для компьютера и телефона.

## Стек

- PHP 8.2+ и PDO PostgreSQL.
- PostgreSQL 15+.
- HTML5, CSS3, JavaScript.

## Запуск на macOS

Нужны PHP с расширением pdo_pgsql и запущенный PostgreSQL. По умолчанию приложение ожидает PostgreSQL на 127.0.0.1:5433 и базу playvault. Если порт или пользователь другие, измените config.php.

Для **новой пустой базы** из папки проекта:

~~~bash
"$(brew --prefix postgresql@18)/bin/createdb" -h 127.0.0.1 -p 5433 -U "$USER" playvault
"$(brew --prefix postgresql@18)/bin/psql" -v ON_ERROR_STOP=1 -h 127.0.0.1 -p 5433 -U "$USER" -d playvault -f database/schema.sql
cp config.example.php config.php
php -S localhost:8000 -t public
~~~

Откройте http://localhost:8000 и зарегистрируйте аккаунт. В пустой коллекции можно загрузить пять демонстрационных игр.

Если база playvault уже существует и содержит все пять актуальных таблиц, **не создавайте её повторно и не выполняйте schema.sql поверх рабочей базы**. Достаточно проверить config.php и запустить PHP-сервер.

## Структура проекта

~~~text

~~~

## База данных

Схема состоит из пяти таблиц:

| Таблица | Назначение |
| --- | --- |
| users | Аккаунты и хеши паролей |
| genres | Справочник жанров |
| games | Общий каталог названий игр |
| platforms | Справочник платформ |
| collection_items | Личные записи игр, оценки и прогресс |

Таблицы связаны внешними ключами. Ограничение UNIQUE (user_id, game_id, platform_id) запрещает повтор одной игры на одной платформе у одного пользователя, но позволяет добавить её другому пользователю. Значения статуса, рейтинга и часов ограничены через CHECK.

## Безопасность

- Пароли хранятся в виде хешей (password_hash, password_verify).
- Работа с личной коллекцией ограничивается user_id из PHP-сессии.
- Пользовательский ввод передаётся в SQL через подготовленные запросы PDO.
- Изменяющие формы защищены CSRF-токеном.
- Файл config.php с параметрами подключения исключён из Git через .gitignore.

Встроенный PHP-сервер предназначен для локальной разработки. Для публичного размещения потребуются HTTPS и дополнительные меры безопасности.
